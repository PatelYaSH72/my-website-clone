# CA Fenil Shah — Chartered Accountant & Strategic Financial Advisory

High-end executive website for **CA Fenil Shah** (FCA, IBBI Registered Valuer), featuring strategic corporate finance advisory, Pre-IPO due diligence, capital restructuring, forensic audits, and boardroom governance.

## Tech Stack
- **Framework:** Next.js 16 (App Router, React 19, TypeScript strict)
- **Styling:** Tailwind CSS v4 with bespoke luxury design tokens (Midnight Royal Navy `#080F1E`, Royal Blue Radial Gradients, Subtle Yellow `#E6C654`, Warm Ivory `#F3EFE6`)
- **Animation:** GSAP 3 + ScrollTrigger, `@gsap/react`
- **Components:** shadcn/ui primitives, Lucide React

## Getting Started

### Prerequisites
- Node.js >= 20
- npm

### Installation
```bash
git clone https://github.com/PatelYaSH72/my-website-clone.git
cd my-website-clone
npm install
```

### Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the site.

### Build
```bash
npm run build
npm run start
```

### Verification
```bash
npm run check   # Runs lint, typecheck, and build
```
